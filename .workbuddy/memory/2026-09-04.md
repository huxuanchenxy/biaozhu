# 2026-09-04

## 路由模式改为 hash（承接 09-03 脚手架）

- 起因：用户访问 http://localhost:3001/home 发现 URL 没有 `#`，希望改成 hash 模式
- 改动：
  - `src/router/index.ts`：`createWebHistory` → 按 `VITE_ROUTER_MODE` 在 `createWebHashHistory` / `createWebHistory` 间切换
  - `.env` 新增 `VITE_ROUTER_MODE = hash`（默认 hash）
  - `env.d.ts` 补 `VITE_ROUTER_MODE` 类型
  - README 增加「路由模式」「端口」两节
- 验证：`npm run build` 通过；dev 启动正常，`/` 与 `/home` 均返回 200
- 注意：改 `.env` 后必须重启 dev server 才生效（env 在启动时加载，HMR 不会重新读）

## 环境情况

- 本机 3000、3001 端口当时都被其他 node 进程占用，Vite 会自动顺延到 3002，启动日志会写明实际端口
- 用户当时跑的是 3001 上的实例；我做冒烟测试起的 3002 实例已用 Stop-Process 清理，3000/3001 未动
