## 环境坑：Vite 缓存目录删除失败导致 dev 起不来

- 现象：`npm install` 后首次 `vite` 报 `[safe-delete] 操作失败 ... node_modules\.vite\deps`
- 原因：Vite 要删 `node_modules/.vite/deps` 重建预构建缓存，沙箱的 safe-delete shim（genie-trash）对该路径失败
- 解决：`mv node_modules/.vite node_modules/.vite_bak_<时间戳>` 改名绕过（不要用 rm），Vite 会重新生成
- 同样的坑也在 `vite build` 清空 `dist/assets` 时出现 → 先 `mv dist dist_bak_<时间戳>` 再 build
- dev server 用后台任务 kill 后端口不一定释放，再启动会报 `Port already in use`；用 PowerShell
  `Get-NetTCPConnection -LocalPort <port> -State Listen | Select -ExpandProperty OwningProcess | Stop-Process -Force`
